# Motifuse SDK examples

These TypeScript examples compile in CI and map to current public API operations. Set
`MOTIFUSE_API_KEY` in your shell or secret manager; do not commit `.env` files.

- `quickstart`: list Spectrace projects
- `docforge`: create a generation and wait for completion
- `reconova`: direct-upload a workbook and start cleaning
- `spectrace`: create a project and deterministic comparison
- `jobs`: retrieve and wait for asynchronous work
- `webhooks`: verify a raw webhook body
- `errors`: retain API diagnostics
- `idempotency`: repeat a mutation safely
